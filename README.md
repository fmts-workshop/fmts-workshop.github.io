# FMTS @ NeurIPS 2026

Website for **Foundation Models for Temporal Systems: From Forecasting to World Modeling**, a
one-day workshop at [NeurIPS 2026](https://neurips.cc/Conferences/2026/) in Sydney.

Live at **<https://fmts-workshop.github.io>**. Static HTML and CSS — no build step. Serve locally
with `python3 -m http.server 8000`; pushing to `main` deploys via GitHub Pages.

Contact: <fmts-neurips2026@googlegroups.com>
